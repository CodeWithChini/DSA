<h1>Valid Palindrome</h1>

A phrase is a palindrome if, after converting all uppercase letters into lowercase <br>
letters and removing all non-alphanumeric characters, it reads the same forward and <br>backward. Alphanumeric characters include letters and numbers.


<h3>Example 1:</h3>

Input: s = "A man, a plan, a canal: Panama"<br>
Output: true<br>
Explanation: "amanaplanacanalpanama" is a palindrome.<br>

<h3>Example 2:</h3>

Input: s = "race a car"<br>
Output: false<br>
Explanation: "raceacar" is not a palindrome.<br>

<h3>Example 3:</h3>

Input: s = " "<br>
Output: true<br>
Explanation: s is an empty string "" after removing non-alphanumeric characters.<br>
Since an empty string reads the same forward and backward, it is a palindrome.<br>

<h3>Constraints:</h3>

1 <= s.length <= 2 * 105<br>
s consists only of printable ASCII characters.
